
# Whorder

*(Cloudflare Workers/KV, Angular)*

KPNC Technology: Whorder (Who-Order) is a simple web app that helps you keep track of your Doctor Who watch history and liked episodes. Whorder provides a chronological list of Doctor Who episodes (new, old, and spin-off) and can be editted to remove or add specific collections like the spin-offs, specials, movies, etc...

Check it out at [whorder.com](https://whorder.com/)

Your random list ID is saved in your browser, so make sure to write it down somewhere before your browser's local storage gets wiped...
